\section{System Architecture Overview}
The Soft L-Topological Neural Network is an autoregressive and bidirectional language modeling architecture that replaces unconstrained Euclidean vector spaces and dense softmax routing with \textbf{bounded continuous soft set representations} and \textbf{nilpotent lattice sequence routing}.

The overall forward data flow proceeds as follows:
\begin{enumerate}
    \item Input discrete tokens $w_t \in \mathcal{V}$ are embedded directly into the continuous unit hypercube $[0, 1]^D$.
    \item Bounded learnable positional encodings in $[0, 1]^D$ are combined with token representations via convex blending.
    \item A stack of $L$ identical \textbf{Lattice Blocks} processes the representations, each combining a multi-head continuous lattice router, residual connections, and position-wise feed-forward networks (FFN).
    \item A final linear projection computes next-token logits over the vocabulary.
\end{enumerate}

\section{Bounded Continuous Lattice Embeddings}
To apply continuous logic, representations must remain strictly bounded in $[0, 1]^D$ without arbitrary magnitude drift.

\subsection{Convex Token and Positional Blending}
Raw embedding parameters $\widetilde{E} \in \mathbb{R}^{|\mathcal{V}| \times D}$ and positional parameters $\widetilde{P} \in \mathbb{R}^{S \times D}$ are normalized via element-wise sigmoid:
\begin{equation}
\mathbf{e}_{\text{tok}}(w) = \sigma(\widetilde{E}_w) \in (0, 1)^D, \quad \mathbf{e}_{\text{pos}}(t) = \sigma(\widetilde{P}_t) \in (0, 1)^D
\end{equation}
Instead of unconstrained addition ($x_{\text{tok}} + x_{\text{pos}}$), they are combined via \textbf{convex blending} with coefficient $\lambda = 0.5$:
\begin{equation}
\label{eq:convex_blending}
\mathbf{x}_t^{(0)} = \lambda \mathbf{e}_{\text{tok}}(w_t) + (1 - \lambda) \mathbf{e}_{\text{pos}}(t)
\end{equation}
Because the unit hypercube $[0, 1]^D$ is convex, $\mathbf{x}_t^{(0)} \in [0, 1]^D$ holds strictly for all sequence positions.

\subsection{Beta Distribution Initialization}
Standard Gaussian initialization centered at zero produces uniform memberships near $0.5$ under sigmoid. To encourage diverse attribute specialization, raw embedding weights are initialized using an asymmetric \textbf{Beta distribution}:
\begin{equation}
\widetilde{E}_{vd} \sim \text{logit}(\text{Beta}(\alpha, \beta)), \quad \alpha = 1.0, \, \beta = 3.0
\end{equation}
This concentrates initial memberships between $0.1$ and $0.4$, setting most attribute pairs near or below the nilpotent threshold at initialization.

\section{The Continuous Lattice Sequence Router}
Given sequence representations $X \in \mathbb{R}^{S \times D}$, the router projects hidden states into $H$ parallel heads ($d_k = D / H$):
\begin{align}
Q^{(h)} &= \sigma(X W_Q^{(h)}) \in [0, 1]^{S \times d_k} \quad &\text{(Queries as fuzzy attribute requirements)} \\
K^{(h)} &= \sigma(X W_K^{(h)}) \in [0, 1]^{S \times d_k} \quad &\text{(Keys as fuzzy attribute satisfactions)} \\
V^{(h)} &= X W_V^{(h)} \in \mathbb{R}^{S \times d_v} \quad &\text{(Values as unconstrained semantic features)}
\end{align}
Notice that Queries and Keys are bounded in $[0, 1]^{S \times d_k}$ to serve as truth membership functions, while Values ($V^{(h)}$) remain in unconstrained Euclidean space $\mathbb{R}^{S \times d_v}$ to preserve rich feature capacity.

\subsection{Thresholded \L{}ukasiewicz Conjunction}
For each head $h$, the multi-attribute semantic conjunction between query token $i$ and key token $j$ is computed using the thresholded \L{}ukasiewicz $t$-norm with activation threshold $\tau \ge 0$:
\begin{equation}
\label{eq:thresholded_lukasiewicz}
\mathcal{M}_{ijd}^{(h)} = \max(0, Q_{id}^{(h)} + K_{jd}^{(h)} - 1 - \tau)
\end{equation}
Total attribute overlap is the sum of active conjunctions across the $d_k$ latent dimensions:
\begin{equation}
\mathcal{C}_{ij}^{(h)} = \sum_{d=1}^{d_k} \max(0, Q_{id}^{(h)} + K_{jd}^{(h)} - 1 - \tau)
\end{equation}
If $Q_{id}^{(h)} + K_{jd}^{(h)} \le 1 + \tau$ for all coordinates, the overlap $\mathcal{C}_{ij}^{(h)}$ evaluates strictly and identically to \textbf{0.0000}.

\subsection{Continuous Jaccard Relative Containment}
To normalize the routing scores without risking division by zero, we compute the \textbf{continuous Jaccard containment coefficient} by dividing the conjunction by the fuzzy algebraic union ($t$-conorm):
\begin{equation}
\label{eq:jaccard_routing}
R_{ij}^{(h)} = \frac{\sum_{d=1}^{d_k} \max(0, Q_{id}^{(h)} + K_{jd}^{(h)} - 1 - \tau)}{\sum_{d=1}^{d_k} \left(Q_{id}^{(h)} + K_{jd}^{(h)} - Q_{id}^{(h)} K_{jd}^{(h)}\right) + \epsilon}
\end{equation}
where $\epsilon = 10^{-7}$. This formulation ensures that $0.0000 \le R_{ij}^{(h)} \le 1.0000$ always, and $R_{ij}^{(h)} \equiv 0.0000$ whenever the numerator is zero.

\subsection{Causal Masking and Value Aggregation}
For autoregressive generation, future connections are set directly to zero ($R_{ij}^{(h)} = 0.0000$ for $j > i$). Output representations are formed via value aggregation followed by multi-head projection and a standard two-layer GELU feed-forward network:
\begin{equation}
\text{Head}^{(h)}_i = \sum_{j=1}^i R_{ij}^{(h)} V_j^{(h)}, \quad X^{(l+1)} = X^{(l)\prime} + \text{FFN}(\text{LayerNorm}(X^{(l)\prime}))
\end{equation}

\section{Continuous Lattice KV-Caching}
During autoregressive decoding, recomputing the entire sequence at each step incurs $O(S^2)$ cost. In the Soft L-Topological model, Key-Value caching stores past continuous keys $K_{\text{past}} \in [0, 1]^{t \times d_k}$ and values $V_{\text{past}} \in \mathbb{R}^{t \times d_v}$. At step $t$, the single new query $q_t$ evaluates Equation \ref{eq:jaccard_routing} against the stored keys, reducing decoding cost to $O(T)$.

To guarantee numerical stability when a newly generated token shares insufficient overlap with all prior tokens (including itself), the router applies an \textbf{exact causal diagonal fallback}: if $\sum_{j \le t} R_{tj} < 10^{-6}$, it sets $R_{tt} = 1.0$, preserving the token's own state. 

Across our test suite, cached generation matched full-sequence generation with machine epsilon numerical parity:
\begin{equation}
\Delta = \max | X_{\text{cached}} - X_{\text{uncached}} | = 5.06 \times 10^{-7}
\end{equation}
confirming exact mathematical equivalence.
