\section{The Standard Transformer and Softmax Bottleneck}
The Transformer architecture \cite{vaswani2017attention} builds representations by projecting input tokens $X \in \mathbb{R}^{S \times D}$ into Queries ($Q = X W_Q$), Keys ($K = X W_K$), and Values ($V = X W_V$). Dot products between queries and keys are scaled and normalized row-by-row with softmax:
\begin{equation}
P_{ij} = \frac{\exp(Q_i K_j^T / \sqrt{d_k})}{\sum_{k=1}^S \exp(Q_i K_k^T / \sqrt{d_k})}, \quad \text{Attention}(Q, K, V)_i = \sum_{j=1}^S P_{ij} V_j
\end{equation}

\begin{Proposition}[Strict Positivity of Softmax]
Let $\mathbf{z} \in \mathbb{R}^{S}$ be any finite vector of logits. Then for all $j \in \{1, \dots, S\}$, $P_j = \frac{\exp(z_j)}{\sum_{k=1}^S \exp(z_k)} > 0$, and output probability $P_j = 0$ if and only if $z_j \to -\infty$.
\end{Proposition}
Because real computers use finite floating-point numbers, logits never reach negative infinity. As a result, $P_{ij}$ is positive for every token pair. In longer documents, even completely unrelated words end up with tiny weights between $10^{-3}$ and $10^{-6}$. Stacked across many layers, these small numbers compound. Distractor information leaks into the contextual embeddings, which often leads to factual errors during text generation \cite{ji2023survey}.

\section{Prior Approaches to Sparsity}
Prior work has looked at two common ways to sparsify attention:
\begin{itemize}[itemsep=1.0pt, topsep=1.5pt, parsep=0pt]
    \item \textbf{Fixed Structural Sparsity:} Models like Longformer \cite{beltagy2020longformer} and BigBird \cite{zaheer2020bigbird} restrict attention to local windows or strided intervals. This lowers computation, but the attention pattern is rigid and cannot adapt to what the tokens actually mean.
    \item \textbf{Simplex Activation Sparsity:} Sparsemax \cite{martins2016sparsemax} projects logits onto the probability simplex to produce hard zeros. However, tokens outside the active set get zero gradients, which often causes optimization instability. Entmax \cite{peters2019sparse} smooths this using Tsallis entropy, but requires iterative root-finding that slows down execution.
\end{itemize}

\section{Soft Set Theory and Continuous Lattices}
To let the model dynamically sever connections between unrelated words based on content, we look to \textbf{Soft Set Theory}, originally proposed by Molodtsov \cite{molodtsov1999soft} to handle parameterized uncertainty.
\begin{Definition}[Soft Set]
Let $U$ be a universe of objects and $E$ a set of parameters. A pair $(F, E)$ is called a \textbf{soft set} over $U$ if $F$ is a mapping $F: E \to \mathcal{P}(U)$, where $\mathcal{P}(U)$ is the power set of $U$.
\end{Definition}
Maji et al. \cite{maji2001fuzzy} introduced \textit{Fuzzy Soft Sets}, where parameters take on continuous membership values in $[0, 1]$. Pai and Baiju \cite{pai2021soft} then established \textit{Soft Lattice Topological Spaces}, connecting soft sets to continuous algebraic lattices. We adapt this idea directly to neural sequence modeling: every discrete word $w$ is mapped to a continuous soft set inside the unit cube $\mathbf{x} \in [0, 1]^D$, where each coordinate $x_d \in [0, 1]$ represents the truth value or satisfaction degree of a latent semantic attribute.

\section{Triangular Norms and the Nilpotent Advantage}
To compute logical conjunctions (intersections) on $[0, 1]^D$, we employ \textbf{Triangular Norms ($t$-norms)} \cite{klement2000triangular}, which satisfy commutativity, associativity, monotonicity, and boundary conditions ($T(a, 1) = a, T(a, 0) = 0$).

\bottomrule
\end{tabular}
\end{table}

A $t$-norm is considered \textbf{nilpotent} when it can return zero for inputs that are strictly greater than zero. In the \L{}ukasiewicz case, $T_L(a, b) = \max(0, a + b - 1) = 0$ whenever $a + b \le 1$. While operators like G\"odel or Product stay positive as long as inputs are positive, \L{}ukasiewicz gives a real mathematical floor at zero. At the same time, when $a + b > 1$, the partial derivatives are constant ($\frac{\partial T_L}{\partial a} = \frac{\partial T_L}{\partial b} = 1.0$). This allows gradients to backpropagate cleanly through active connections without saturating.
